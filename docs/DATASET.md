Download the Slicer volumes (checked against the SHA-256 digests published in Slicer's
SampleData module):

```bash
python tools/download_slicer_data.py                 # all
python tools/download_slicer_data.py CTChest MRBrainTumor1
```

Regenerate the phantoms and the plane CSV files:

```bash
python tools/generate_dataset.py
```

```bash
python tools/make_planes.py volume.nrrd planes.csv --frames 48
```

### The invalid lines used everywhere

| CSV line | Why it is invalid | Reported message |
|---|---|---|
| `10,0,60, 0,100,60, 30,100,60` | `dist(a,b) ≠ dist(a,c)` | `not isosceles: …` |
| `1,2,3, 4,5,6` | only 2 points | `expected 9 (3 points) or 12 (4 points) numbers, got 6` |
| `10,0,60, abc,100,60, 20,100,60` | text in a coordinate | `non-numeric value(s): abc` |
| `40,0,60, 80,0,70, 0,100,60, 120,100,70` | equal legs but 4 points not on one plane | `points are not coplanar …` |

## MRHead axes (index space)

From the header's `space directions` (LPS): index `x` → posterior (+1 mm), index `y` → inferior
(1 mm), index `z` → right (1.3 mm). A plane with constant `z` is therefore an upright sagittal
slice when its rows run along +`y`.
